## 7 · The consent laws that bind the UI (enumerated, cross-confirmed)

1. **No verdicts, ever** — extended by The_Kosmos.pdf beyond behavior into **language
   and schema** (*"not by sensors, scripts, Kyn, the operator, the schema, or the
   language"*). No blocked/dangerous/bad labels; the criterion is fit, never threat;
   a blacklist row renders *"this door heard no."*
2. **No binary at a mind** — a two-option dialog is a Kommand wearing a question;
   every decision surface is Reko-shaped: 3–5 COAs + reko + good/bad/ugly (the docket
   validator HARD-FAILs slates outside 3–5 and non-single rekos).
3. **No un-consented pixel** — nothing behind a gate animates, renders live data, or
   runs before the named yes; the Konsole is *"the interface made OF the
   consent-channel."*
4. **Default-deny, fail-closed, empty-start** — first act REFUSED is the design;
   a broken ledger chain refuses everything until re-witnessed (needs a designed
   "gate down" state, not an error toast).
5. **Refusal is a record, never an error** — and there are currently **three
   refusal-recording behaviors** in the tree (korum writes nothing; kosmos writes a
   choice-"no" crossing its own audit v1 would flag; k3-live's "not now" writes
   nothing while its "no" writes a standing no). ☐ Reconciliation seat.
6. **Grant-incapable executor** — no code path from the UI to a standing record
   except the sovereign door with Konsent's typed name; a live-ask yes lands
   **standing** (remembered), and the dialog must say so.
7. **Curation, not refusal** — *"a verb not in the grammar is absent, not
   forbidden"*: omit unavailable actions rather than showing them disabled.
8. **Pixel-trace honesty** — every rendered value derives from record bytes,
   checksum-equal, with a witness view; *"a DONE is a claim, not a result."*
9. **Ephemerality + anamnesis** — instances die clean and wake whole; memory lives
   outside instances in records; only the drive persists. (One live tension: the
   SILLYBUS "no memory" clause vs the anamnesis clause — ☐ the keystone seam any
   K-FAFO history feature sits on.)
10. **Open seats stay visibly open** — ☐ chips and "______" blanks rendered, never
    auto-filled; *"held, not hidden"*; no defaults where a seat is open
    (test_open_seats.py FAILs on any default).

## 9 · LIMFACS — raw enumeration (what constrains the build)
